Details optional

Year and month put each issue in reading order across series. An omnibus takes its dates from its contents file.

Takes a while: every page goes through the vision model the first time. Reading again is instant.

Omnibus

Where each issue starts

An omnibus holds many issues in one file. Its contents file tells litmapr where each one begins, so every issue gets its own place in the reading order. Add comics uses it automatically.

One issue per line: first page, series, issue, year, month. N, skip leaves out pages from N on (ads, sketches). Lines starting with # are notes.

Tidy up

Merge duplicates, find callbacks

Merge duplicates

Finds entries that are one character under two names ("Invisible Woman" and "Susan Storm"), and checks each pair with the text model before merging. Preview first: it shows the decisions without changing anything.

Merge two by hand

For a pair the model missed. The second one is folded into the first, with its appearances, connections and picture.

Find callbacks

Looks for later moments that echo earlier ones across issues, like a device that comes back. Run it after adding new issues.

Models

Which local models do the work

Any model you have in Ollama. Leave a box empty for the default. Saved in this browser.

Missing a model? In a terminal: ollama pull qwen2.5vl:3b. The narrator's model is set when the server starts: litmapr studio --model qwen3:4b-instruct.
